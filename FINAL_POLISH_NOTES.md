# HESTIA final polish

The current working project is preserved. Only additive final-polish fixes are included:

- System Back from property details returns to Home; secondary screens follow the existing logical navigation stack.
- The platform action bar is removed and system-bar-safe spacing is applied so screen content is not vertically clipped.
- Login no longer shows or pre-fills the demo buyer shortcut.
- Property details now provide a swipeable multi-image gallery, thumbnails, and an image counter.
- The backend automatically tops existing properties up to at least three images without deleting current images.
- New seed runs create three images per property.
